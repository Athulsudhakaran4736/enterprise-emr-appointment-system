# Enterprise EMR Appointment Management System

A production-oriented appointment management module developed as part of a MERN Stack Developer technical assessment.

## Technology Stack

### Frontend

- React
- React Router
- Axios
- Socket.IO Client

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Socket.IO

## Main Features

- Access-token and refresh-token authentication
- Role-based access control
- Doctor schedule management
- Dynamic slot generation
- Appointment booking
- Double-booking prevention
- Appointment status workflow
- Search, filtering and pagination
- Audit logging
- Real-time appointment updates

## Project Structure

- `client` – React frontend
- `server` – Express backend
- `docs` – diagrams and API documentation
- `ENGINEERING_DECISIONS.md` – architecture and engineering decisions
